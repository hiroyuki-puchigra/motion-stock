以下の条件で、提案リストを作成してください。

条件：$ARGUMENTS

## 手順

1. **候補選定**：`src/content/animations/` から条件に合うものを選ぶ。指定したIDがあればそれを優先する（一覧ページの「候補リスト」からコピーしたID列が渡されることもある）。条件に合うものが足りない場合は、無理に埋めず不足を伝える
2. **構成案の提示**：以下を表で提示して確認を取る
   - 提案箇所（例：トップMV、施工事例）/ アニメーションID・タイトル / 選定理由
   - 全体のイントロ文案
3. **作成**：`src/content/proposals/[slug].json` を作成する
   - slug は `{クライアント名ローマ字}-{ランダム6文字}`。ランダム部分は小文字英数字のみ、ファイル名も `[slug].json` と一致させる
   - `items` の `id` は実在するアニメーションIDのみ。`comment` は空文字でもよい
   - コメントはクライアントが読む前提で、専門用語を避け、サイトにどう効くかを書く
4. **検証**：`npm run validate` を通す
5. **確認依頼**：ローカルURL（`/p/[slug]/`）を提示する。参考元URLなど社内情報が出ていないことも確認する
6. **公開**：OKが出たら `feat: 提案リスト [クライアント名] を追加` でcommitし、pushして共有URLを提示する（gitリポジトリが未初期化・リモート未設定の場合は、commitせずその旨を伝える）
