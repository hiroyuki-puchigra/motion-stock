以下の参考情報をもとに、アニメーションをストックに追加してください。

参考情報：$ARGUMENTS

## 手順

1. **把握**：参考URLを確認し、対象の動きを特定する。特定できない場合は、どの箇所の動きか質問する
2. **分類案の提示**：実装前に、以下を表で提示して確認を取る
   - ID（`{part}-{3桁連番}`。`src/content/animations/` の既存最大番号 + 1）
   - タイトル案（20文字以内）/ 部品 / きっかけ / 印象（1〜3個）/ 技術 / 工数 / 負荷 / SP対応
   - taxonomy にない値が必要になる場合は、追加せずここで確認する
   - 実装方針（CSSのみで可能か、GSAPが必要か等）
3. **実装**：CLAUDE.md の「他サイトの動きを追加するときのルール」「デモ実装ルール」に従い、`public/demos/[id]/` に再現実装する（コードは流用しない）
   - きっかけが `hover` の場合は、`index.html` の `<head>` に `<meta name="preview-hover" content=".対象セレクタ">` を置く
   - スクロール系は、スクロール55%付近に見せ場が来る高さ構成にする（ポスターをその位置で撮るため）
4. **meta作成**：`src/content/animations/[id].json` を作成する。`reference` に参考URLと一言メモを記録し、`npm run validate` を通す
5. **プレビュー生成**：`npm run preview:record -- [id]` を実行し、`preview.webm` / `preview.mp4` / `poster.jpg` ができたことを確認する（ポスターは画像を開いて、見せ場が写っているか見る）
6. **確認依頼**：ローカルURL（`/a/[id]/`）を提示し、ユーザーの確認を待つ。SP幅（375px）の見え方と、背景の白黒切替も合わせて確認しておく
7. **公開**：OKが出たら `feat: [id] タイトル を追加` でcommitし、pushする（gitリポジトリが未初期化・リモート未設定の場合は、commitせずその旨を伝える）

参考URLが動画・GIF・スクリーンショットの場合も、同じ手順で進めてください。
